4. الميزة التنافسية الفريدة

🏆 لماذا سننجح حيث فشل الآخرون؟

1️⃣ التكامل الثلاثي الفريد (Triple Integration)

لا يوجد منافس عربي يقدّم هذا التكامل بين ثلاثة عناصر في منصّة واحدة:

📚 محتوى غني (كتب)
        ↕
   🔗 تكامل عضوي
        ↕
🎮 تجربة ممتعة (ألغاز)
        ↕
   📊 ذكاء تكيّفي

2️⃣ منهجية "اقرأ-العب-أتقن" (Read-Play-Master)

كل كتاب يمرّ بثلاث مراحل تضمن التعلّم الفعّال:

📖 اقرأ فصل من الكتاب

↓

🎮 العب ألغازاً مبنية على محتوى الفصل

↓

🏆 احصل على نجمة إتقان لهذا الفصل

↓

✅ عند إكمال كل الفصول + الألغاز → شهادة إتقان

3️⃣ التكيّف الذكي

المكتبة تتكيّف مع سلوك اللاعب واهتماماته:

  • يقرأ كتاباً عن الشعر → تقترح كتب شعر أخرى
  • يخطئ في ألغاز الأمثال → تقترح كتاب "أمثال العرب"
  • يكمل كتاباً صعباً → تقترح كتباً بمستوى أعلى
  • يحبّ قصص الأطفال → تقترح كتباً مشابهة

4️⃣ محتوى أصيل وموثّق

  • كل كتاب مُراجَع من خبراء متخصّصين
  • كل لغز مرتبط بفقرات محددة من الكتاب
  • نسبة دقة 100% في المعلومات
  • مصادر موثّقة لكل محتوى

6. تصميم تجربة المستخدم

🎨 مبادئ التصميم

1. البساطة أولاً (Simplicity First)

  • 3 نقرات كحد أقصى للوصول لأي كتاب
  • بحث فوري أثناء الكتابة
  • ترشيحات ذكية بناءً على السلوك

2. القراءة المريحة (Comfortable Reading)

  • خطوط عربية مُحسّنة (Tajawal, Cairo, Noto Naskh)
  • تباعد أسطر مريح (1.8)
  • عرض الصفحة محدود (max-width: 700px)
  • وضع ليلي تلقائي حسب وقت النظام

3. التكامل السلس (Seamless Integration)

  • الانتقال من القراءة للّعب بنقرة واحدة
  • نفس نظام النجوم والعملات
  • إحصائيات موحّدة في الملف الشخصي

📱 تخطيط الصفحات

صفحة المكتبة الرئيسية

تحتوي على:

  • شريط بحث في الأعلى
  • قسم "كتاب اليوم" المميّز
  • شبكة التصنيفات (8 فئات)
  • "استكمال القراءة" للكتب الجارية
  • "الأكثر قراءة هذا الأسبوع"
  • "توصيات لك" بناءً على السلوك

صفحة الكتاب

تعرض:

  • صورة الغلاف + معلومات أساسية
  • التقييم والإحصائيات
  • الوصف والأهداف التعلّمية
  • قائمة الفصول مع حالة كل فصل
  • أزرار: ابدأ القراءة / تنزيل PDF / ألغاز الكتاب
  • المراجعات والتقييمات

قارئ الكتب الذكي

ميزات القارئ:

  • قارئ ويب متجاوب يعمل على كل الأجهزة
  • وضع ليلي مع تبديل تلقائي
  • تكبير/تصغير الخط (4 مستويات)
  • إشارات مرجعية بنقرة واحدة
  • ملاحظات شخصية على أي فقرة
  • شريط تقدّم علوي
  • زر "التالي" و"السابق" للتنقّل بين الفصول
  • تتبّع تلقائي لآخر موضع قراءة

9. نموذج الربح

💰 استراتيجية الربح المتعدّدة

1️⃣ Freemium Model

🆓 المستخدم المجاني

  • تصفّح كل المكتبة
  • قراءة 20% من كل كتاب (معاينة)
  • 3 كتب كاملة شهرياً (تتغيّر)
  • ألغاز الكتب المجانية
  • إعلانات بسيطة (non-intrusive)

💎 Premium (29 ريال/شهر)

  • قراءة غير محدودة لكل الكتب
  • تنزيل PDFs كاملة
  • كتب صوتية
  • بدون إعلانات
  • إحصائيات متقدّمة
  • شهادات إتقان معتمدة
  • كتب حصرية (Premium-only)
  • دعم أولوية

🏫 حسابات المدرسة

  • 50+ حساب طالب

  • تقارير دورية
  • مهام معيّنة
  • ربط بالمنهج السعودي/المصري
  • شهادات معتمدة
  • دعم مخصّص

السعر: 5 ريال/طالب/شهر

1. تصنيفات الكتب (BookCategory)

model BookCategory {
  id          Int      @id @default(autoincrement())
  name        String   @unique
  slug        String   @unique
  icon        String   @default("📚")
  color       String   @default("#3b82f6")
  description String   @default("")
  order       Int      @default(0)
  isPublished Boolean  @default(true)
  books       Book[]

}

2. الكتب (Book)

model Book {
  id              Int      @id @default(autoincrement())
  categoryId      Int
  title           String
  author          String
  description     String   @default("")
  coverImage      String   @default("")
  
  // نوع المحتوى
  contentType     String   @default("text")  // text | pdf | audio
  pdfUrl          String   @default("")
  audioUrl        String   @default("")
  
  // خصائص
  difficulty      String   @default("medium")
  readingTimeMin  Int      @default(15)
  pages           Int      @default(0)
  language        String   @default("ar")
  isbn            String?  @unique
  
  // الكلمات المفتاحية (JSON array)
  keywords        String   @default("[]")
  
  // الإحصائيات
  views           Int      @default(0)
  downloads       Int      @default(0)
  ratingAvg       Float    @default(0)
  ratingCount     Int      @default(0)
  
  // الحالة
  isPublished     Boolean  @default(false)
  isFeatured      Boolean  @default(false)
  isPremium       Boolean  @default(false)
  
  // علاقات
  category        BookCategory @relation(fields: [categoryId], references: [id])
  chapters        BookChapter[]
  bookmarks       UserBookmark[]
  reviews         BookReview[]
  readingProgress UserReadingProgress[]
  
  // ربط مع اللعبة
  relatedLevels   String   @default("[]")
  
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
  
  @@index([categoryId])
  @@index([isPublished])
}

3. فصول الكتاب (BookChapter)

model BookChapter {
  id              Int      @id @default(autoincrement())
  bookId          Int
  number          Int
  title           String
  content         String   @default("")
  readingTimeMin  Int      @default(5)
  isFree          Boolean  @default(true)
  isPublished     Boolean  @default(true)
  keywords        String   @default("[]")
  relatedLevelId  Int?
  
  book            Book     @relation(fields: [bookId], references: [id], onDelete: Cascade)
  
  @@index([bookId])
}

النماذج المتبقية

هناك 4 نماذج إضافية:

  • UserBookmark — الإشارات المرجعية
  • BookReview — التقييمات والمراجعات
  • UserReadingProgress — تتبّع تقدّم القراءة
  • UserCertificate — شهادات الإتقان

تفاصيل كل نموذج موجودة في الملف الكامل docs/LIBRARY-STUDY.md.
