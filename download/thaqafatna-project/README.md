# 🎮 تطبيق ثقافتنا - لعبة كلمات متقاطعة عربية

منصة ثقافية تفاعلية تجمع بين الألغاز والكلمات المتقاطعة العربية، تثري اللاعب ثقافياً عبر 8 فصول متنوعة.

## 📋 المحتويات

### البنية التقنية
- **Framework**: Next.js 16 (App Router)
- **Language**: TypeScript 5
- **Database**: Prisma ORM + SQLite
- **Styling**: Tailwind CSS 4 + shadcn/ui
- **Animations**: Framer Motion
- **State Management**: Zustand (مع persistence)
- **Fonts**: Cairo + Tajawal (Google Fonts)

### نماذج قاعدة البيانات (8 نماذج)
1. **Chapter** - الفصول (8 فصول ثقافية)
2. **Level** - المراحل (37 مرحلة)
3. **Word** - الأسئلة/الكلمات (119 سؤال)
4. **Cell** - خلايا الشبكة
5. **User** - المستخدمون
6. **PlayerProgress** - تقدم اللاعب
7. **DailyChallenge** - التحديات اليومية
8. **UserStreak** - سلاسل المستخدمين

### الفصول الثمانية
1. 🌟 البدايات - كلمات سهلة ومألوفة
2. 🌿 الطبيعة - نباتات وحيوانات
3. 📜 التراث - ثقافة عربية
4. 📜 أمثال عربية - حكم وأمثال
5. 🏛️ شخصيات إسلامية - علماء وقادة
6. 🗺️ جغرافيا عربية - بلدان وأماكن
7. 🔬 علوم وفنون - مصطلحات علمية
8. 📚 شعر وأدب - أبيات وأسماء

### أنواع الألغاز المدعومة
- 📝 **نصي**: سؤال + إجابة + حروف متاحة
- 🖼️ **صورة واحدة**: الصورة كلغز
- 📷 **4 صور**: 4 صور مرتبطة بكلمة واحدة
- 🔤 **شبكة متقاطعة**: سحب الحروف في شبكة

## 🚀 التشغيل

```bash
# تثبيت الحزم
bun install

# إعداد قاعدة البيانات
bun run db:push

# زرع البيانات الأولية
bunx tsx scripts/seed-db.ts
bunx tsx scripts/create-test-levels.ts
bunx tsx scripts/create-cultural-platform.ts
bunx tsx scripts/create-image-levels.ts

# تشغيل الخادم
bun run dev
```
