# 🎮 ثقافتنا — منصة تعليمية ترفيهية عربية

<div dir="rtl">

منصة عربية متكاملة تجمع بين **الألغاز التكيّفية** و**المكتبة الذكية** في مكان واحد. مبنية بأحدث التقنيات لتوفير تجربة تعليمية ترفيهية عربية فريدة.

## ✨ المميزات الرئيسية

### 🎮 النظام الأول: لعبة الكلمات التكيّفية
- **13 نوع لغز** كامل (نصي، صورة، 4 صور، إيموجي، حروف مبعثرة، شبكة متقاطعة، فراغات، توصيل، اختيار من متعدد، صوتي، منطقي، تلميحات متدرجة، بوس)
- **20 مهارة** تكيّفية في 5 جذور هرمية
- **محرّك SM-2** للتكرار المتباعد
- **نظام نجوم إيجابي** (3 نجوم: إنجاز + ذكاء + سرعة)
- **مدقّق جودة آلي** (10 معايير تربوية)
- **موازن صعوبة** (Bloom's + Vygotsky)
- **AI Tutor** للتلميحات الذكية
- **شاشة أهداف تربوية** قبل بدء كل مرحلة
- **لوحة تحليلات** شاملة + خريطة معرفة بصرية
- **Leaderboards** (أسبوعي/شهري/كلي) مع منصّة ذهب/فضة/برونز
- **Push Notifications** + Web Notification API
- **PWA** قابل للتثبيت

### 📚 النظام الثاني: المكتبة الذكية
- **30 كتاب** عربي بمحتوى حقيقي + 68 فصل
- **8 تصنيفات** رئيسية
- **3 صفحات واجهة**: مكتبة رئيسية + صفحة كتاب + قارئ ذكي
- **أغلفة SVG** مولّدة ديناميكياً بألوان حسب التصنيف
- **فلترة + ترتيب** (5 خيارات) + بحث فوري
- **نظام شهادات** إتقان (رقم فريد + PDF)
- **محرّك توصيات** شخصي بناءً على سلوك القراءة
- **إشارات مرجعية** + ملاحظات
- **تتبّع قراءة** تلقائي (كل 5 ثوانٍ + إكمال عند 90%)
- **أداة استيراد PDF** (تحوّل أي PDF إلى كتاب منسّق)
- **لوحة إدارة موحدة** بـ 5 تبويبات

### 🏗️ البنية التحتية
- **23 نموذج DB** (Prisma + SQLite/PostgreSQL)
- **30+ API endpoint**
- **PWA** (manifest.json + offline)
- **Production build** ناجح

## 🚀 التشغيل المحلي

### المتطلبات
- Node.js 18+ 
- npm أو bun

### التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/USERNAME/REPO_NAME.git
cd REPO_NAME

# تثبيت الاعتماديات
npm install

# إعداد قاعدة البيانات
cp .env.example .env
npx prisma generate
npx prisma db push

# زرع البيانات الأولية
npm run db:seed  # أو تشغيل scripts/seed-db.ts

# تشغيل وضع التطوير
npm run dev
```

افتح المتصفح على: http://localhost:3000

## 🏭 الإنتاج

### النشر على Vercel
1. ارفع المستودع إلى GitHub
2. اربطه بـ Vercel
3. أضف متغيرات البيئة:
   - `DATABASE_URL` (Neon PostgreSQL URL)
4. انشر

### النشر على Space-Z / Serverless
المشروع جاهز لبيئات Serverless بفضل منطق نسخ DB التلقائي إلى `/tmp`:

```bash
# إعدادات .env.production
SPACE_Z_DEPLOYMENT=true
DATABASE_URL=file:/app/db/custom.db
```

انظر `docs/DEPLOYMENT.md` للتفاصيل الكاملة.
